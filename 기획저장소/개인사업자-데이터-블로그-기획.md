# 개인사업자·동네 가게 데이터 글 기획

작성: 2026-09-25. 글을 쓰기 전 원표의 개인·법인 구분, 집계 단위, 최종 수록 연도를 재확인한다.

## 공통 원칙

- 국세청 국세통계와 KOSIS 공개 표만 사용한다. 2025년 수록 표가 확인되지만, 각 표의 기간과 항목은 원표에서 확정한다.
- 개인사업자 통계와 개인·법인을 합친 사업자 통계를 섞어 ‘개인사업자’ 전체라고 부르지 않는다.
- 개인 과세사업자는 일반과세자와 간이과세자로 나뉘며, 부가가치세 면세사업자도 별도로 살핀다. 한 과세유형의 매출 자료를 개인사업자 전체로 대표하지 않는다.
- 신규·폐업 건수를 서로 나눈 값을 ‘폐업 확률’로 쓰지 않는다. 같은 사업자 집단을 추적한 생존율이 아니다.
- 부가가치세 과세표준·수입금액은 순이익이나 사장님의 실수령액이 아니다. 간이과세자·창업 일반사업자 표도 전체 개인사업자의 평균 매출로 일반화하지 않는다.
- 연도별 변화, 17개 시도 또는 시군구, 업종 비교를 원표 범위에서 시각화한다. 원자료 수치와 단위, 출처를 본문에 함께 보여준다.

## 1. 올해 가게는 얼마나 열고 닫았을까?

질문: 지역별 신규사업자와 폐업자 수가 2016년 이후 어떻게 달라졌을까?

자료: 국세통계 9.8.22 「신규사업자 현황 VI(시·군·구)」, 9.8.16 「폐업자 현황 VII(시·군·구)」. 공개 목록에서 2025년 수록 확인.

구성: 연도별 신규·폐업 두 줄 그래프 → 시도·시군구 비교 → 인구 규모와 사업자 수가 다른 지역 비교의 한계. 원표에 개인사업자 선택 항목이 있는지 확인 후 제목을 확정한다.

## 2. 카페·음식점·미용실, 어디에 새 가게가 많을까?

질문: 100대 생활밀접업종 중 어떤 업종의 신규 등록과 폐업이 많고, 지역마다 어떻게 다를까?

자료: 국세통계 9.8.25 「100대 생활밀접업종 신규 사업자 현황 I(지역, 업종)」, 9.8.26 「… II(월, 업종)」, 9.8.33 「100대 생활밀접업종 폐업 사업자 현황 II(월, 업종)」. 공개 목록에서 2025년 수록 확인.

구성: 업종별 신규·폐업 건수 → 월별 흐름 → 지역 비교. 개인사업자만 분리되는지 확인하지 못하면 ‘동네 가게·사업자’로 표기한다. 같은 해 개업자 중 몇 %가 폐업했는지로 해석하지 않는다.

## 3. 개인사업자는 어느 연령대·지역에 많을까?

질문: 가동사업자 중 개인사업자의 연령·성별·지역 구성은 어떨까?

자료: 국세통계 9.8.9.2 「가동사업자 현황 V(연령, 성, 지역)」. 공개 목록에서 2025년 수록 확인.

구성: 연령대별 분포 → 남녀 비교 → 지역별 구성. 원표의 사업자 유형 선택과 연령 미상 처리 확인. 전체 인구 중 창업률로 해석하지 않는다.

## 4. 개인사업자 매출, 일반과세자와 간이과세자는 어떻게 다를까?

질문: 일반과세자와 간이과세자의 신고 매출 규모 분포는 각각 어떨까?

자료: 국세통계 9.4.4 「간이사업자 업태별·과세표준 규모별 부가가치세 신고 현황」(2013년 이후 표와 2025년 수록 확인), 일반사업자의 부가가치세 신고 현황 표(개인·법인 분리 여부와 과세표준 구간은 원표에서 확인 후 확정). 면세 개인사업자의 사업장현황신고 자료는 별도 범위로 검토한다.

구성: 일반과세자·간이과세자 각각의 규모 구간별 신고 사업자 수 → 업태별 비교 → 연도별 구성 변화. 분류와 과세표준 계산 기준이 다른 표를 금액만으로 단순 비교하지 않는다. 일반과세자에서 개인만 분리할 수 없다면 통합 비교 글로 발행하지 않고 유형별 글로 나눈다. ‘과세표준’을 이익이나 사장님의 실수령액으로 부르지 않는다.

## 5. 새로 연 사업장의 신고 매출은 지역·업종별로 다를까?

질문: 창업 일반사업자의 부가가치세 신고 현황에서 지역·업태별 차이가 보일까?

자료: 국세통계 9.3.6 「창업 일반사업자의 부가가치세 신고 현황(지역, 업태)」. 2007년 이후 표와 2025년 수록 확인.

구성: 신고 인원과 과세표준 등 실제 공개 항목 확인 → 지역·업태 비교 → 연도별 추이. 일반과세자 외 사업자를 포함한 ‘전체 창업 매출’로 확대하지 않는다. 영업 기간이 서로 달라 1년 매출처럼 읽지 않도록 주의한다.

## 추천 발행 순서

1 → 2 → 3 → 4 → 5. 첫 글은 개업·폐업이라는 익숙한 질문으로 시작한다. 4번은 일반과세자의 개인·법인 분리와 비교 가능한 지표를 확인한 뒤 착수한다.

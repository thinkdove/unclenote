# LLM 모델 및 토큰 최적화 사용 기준 (Cost-Saving Routing)

사용자(USER)의 지시를 수행할 때, **작업의 난이도와 특성**에 따라 적절한 모델(Pro 또는 Flash)을 선택하여 토큰(비용)을 최적화하고 응답 속도를 높입니다.

## 1. 모델 라우팅 기준

### Tier 1: Pro 모델 사용 (기본)
- **적용 대상:** 
  - 신규 아키텍처 설계 및 기획 (Planning Mode)
  - 복잡한 비즈니스 로직(세금 계산, 데이터 분석) 구현
  - 난해한 버그 디버깅 및 에러 해결
- **특징:** 높은 추론 능력이 필요할 때 사용합니다.

### Tier 2: Flash 모델 (서브 에이전트 위임)
- **적용 대상:** 
  - 단순 UI/CSS 수정, 텍스트 오타 수정
  - 제공된 가이드라인에 맞춘 반복적인 블로그 글 작성 (단순 텍스트 생성)
  - 대용량 문서 요약 및 기계적 번역 작업
- **실행 방법:** 이 경우, 메인 에이전트(Pro)가 직접 코드를 작성하지 않고, `invoke_subagent` (또는 비슷한 기능)을 사용하여 **가벼운 모델을 가진 서브 에이전트에게 단순 반복 작업을 위임**합니다. 

### Tier 3: 하이브리드 워크플로우
- 기획과 최종 검수는 메인(Pro) 모델이 담당하고, 그 사이의 대량의 마크다운 작성이나 단순 HTML 컴포넌트 찍어내기 같은 노가다 작업은 Flash 모델 기반의 워커(Worker)에게 지시하여 토큰 비용을 최소화합니다.

## 2. 사용자의 명시적 지시
사용자가 프롬프트에 `#Pro` 또는 `#Flash`를 명시한 경우, 해당 지시를 최우선으로 따릅니다.
